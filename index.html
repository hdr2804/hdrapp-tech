01 — About

Research, not checklists.

I am an independent security researcher focused on Web3 protocol security — smart contracts, cross-chain settlement, and the off-chain services that attest to on-chain state.

Every finding I submit is validated end-to-end before it leaves my desk: the vulnerable code is built from its pinned source, the exploit path is executed locally (fork, local validator, or sandbox), the impact is quantified from observed state, and the claim is checked against the public record so maintainers never receive a duplicate.

If a hypothesis cannot be executed, it is not reported as a vulnerability. That discipline is the whole practice.

02 — Focus areas

Where I look.

The recurring theme: places where two components disagree about the state of the world — and the disagreement is worth money.

/01

EVM smart contracts

Accounting desync, access control, proxy & initialization paths, incomplete code paths — verified on mainnet forks at pinned blocks.

/02

Solana programs

Anchor programs and the SPL / Token-2022 surface — extensions, transfer fees, and account-validation gaps, executed on a local validator.

/03

Cross-chain & settlement

Bridges, depositories, allocators and hub accounting — where value moves between chains and every hop is a chance to lose track of it.

/04

DeFi accounting invariants

Gross-vs-net mismatches, share and vesting math, fee handling — the invariant says balances must equal backing; I check that they do.

/05

Oracle & attestation paths

Off-chain attestors and oracle services that mint, transfer, or release funds based on what they believe happened on another chain.

03 — Process

How every report is built.

1

Local validation

The finding is executed against pinned source — fork, local validator, or sandbox. No execution, no report.

2

Whole-web dedupe

The root cause is checked against advisories, audits, and public disclosures so maintainers never get a duplicate.

3

Report with runnable PoC

Root cause, executed proof with exact values, honestly quantified impact, and a concrete fix — PoC attached.

4

Coordinated disclosure

Details stay private while the report is under review. Production systems are observed read-only, never touched.
